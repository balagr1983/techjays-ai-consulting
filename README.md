# Techjays AI Consulting Practice

Working repository for the initiative to launch an AI Consulting wing inside Techjays,
driven by Philip Samuelraj and Bala.

Start with [CONTEXT.md](CONTEXT.md), the living context anchor. It carries the story so far,
positioning, offering shape, decisions, and open action items, and is updated after every
call or new artifact.

## Structure

| Path | Purpose |
|------|---------|
| `CONTEXT.md` | Living working context. Single source of truth for where the initiative stands. |
| `COMMUNICATIONS.md` | Log of key messages and emails once outreach starts. |
| `Transcripts/` | Call transcripts. PDF originals plus extracted text versions. |
| `Research/` | Market intelligence: big-firm AI advisory offerings, network findings, methodologies. |
| `Offering/` | Packaging drafts: service definitions, pricing, positioning, decks. |
| `Notes/` | Working notes that do not fit elsewhere. |

## Conventions

- No em dashes or en dashes in any document.
- Money written as USD 150,000, never "K" shorthand.
- Company name is Techjays.
- Every new transcript gets a dated filename: `YYYY-MM-DD_<participants>_<topic>`.
